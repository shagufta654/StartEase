# StartEase

StartEase helps first-time founders in India start a business without the paperwork confusion.

Sign up, answer a short wizard (business type, state and stage), and get a personalized roadmap covering business registration, Udyam, GST and business-specific licences like FSSAI. Every step shows fees, timelines and required documents, with progress tracking and links to official portals.

## Features
- Login and personal progress tracking
- Fee, time and document estimates for each step
- Funding guide based on your startup stage
- Connect section to find the right professional help
- Startup co-pilot chatbot
- English, Hindi and Marathi support
- Responsive on desktop and mobile

## Tech Stack
HTML, CSS, JavaScript (localStorage). Python backend and database coming soon.

## Run Locally
Clone the repo, open the folder in VS Code and start it with the Live Server extension.
